# Etymology
---
_Yanagi_ is written as 柳:
- "柳": Willow
- Named for the Japanese name of *Chrysaora*, *ヤナギクラゲ属* (Yanagi Kurage Zoku). 
_Ako_ is written as 赤:
- "赤": Red
- Named for the Japanese name of the *Chrysaora pacifica*, 赤クラゲ (Aka kurage).
