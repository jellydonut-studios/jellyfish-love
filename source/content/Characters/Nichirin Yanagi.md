# Etymology
---
_Yanagi_ is written as 柳:
- "柳": Willow
- Named for the Japanese name of *Chrysaora*, *ヤナギクラゲ属* (Yanagi Kurage Zoku). 
_Nichirin_ is written as 日輪:
- "日輪": Sun
- Named for an alternate name of the *Chrysaora melanaster*, "ニチリン柳クラゲ"
